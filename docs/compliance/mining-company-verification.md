# Mining company / project verification

Use this before accepting a mandate or introducing capital. Goal: decide **go / conditional go / no-go**, and which capital type is realistic.

## 1) Identity & corporate

- [ ] Legal name, jurisdiction of incorporation, good standing
- [ ] Cap table / ownership (insiders, promoters, related parties)
- [ ] Officers/directors list + background red flags (SEC/OSC bans, bankruptcies, pump history)
- [ ] Subsidiaries / JV structure / offtake or streaming already in place
- [ ] Public filer? (EDGAR / SEDAR+) — pull latest MD&A, financials, technical report exhibits

**Red flags:** serial failed shells, unexplained related-party payments, promoter-dominated boards with no technical expertise.

## 2) Asset & title

- [ ] Claim / concession / lease schedule (map + claim numbers)
- [ ] Chain of title / option agreements / earn-ins
- [ ] Royalties, NSRs, streaming, government free-carry
- [ ] Surface access, indigenous / community agreements if relevant
- [ ] Encumbrances, litigation, liens

**No-go if:** cannot show clear rights to the ground being financed.

## 3) Technical stage (be precise)

| Stage | Evidence expected | Typical capital |
|---|---|---|
| Exploration / discovery | Drill results, assays, QA/QC | Equity only |
| PEA | PEA report + QP/QP-equivalent | Equity; rarely debt |
| PFS | PFS + updated resources/reserves path | Equity; early royalty talks |
| DFS / FS / “bankable” | Full FS + mine plan + costs | Project equity + debt talks |
| Construction | DFS + permits + offtake/EPC path | Project finance stack |
| Producing | Financials + reserve/resource + ops data | Debt refinance / expansion |

- [ ] Report type and date (PEA / PFS / DFS)
- [ ] Author qualifications (QP under NI 43-101 or SK-1300 qualified person)
- [ ] Resource/reserve classification stated correctly (don’t let marketing blur Inferred → “mineable”)
- [ ] Commodity, grade, recovery, throughput assumptions sanity-check

**Language rule:** never call a PEA “bankable.”

## 4) Permitting & ESG

- [ ] Key permits held vs pending (exploration, environmental, construction, water, tailings)
- [ ] Critical path permit timeline
- [ ] Environmental liabilities / legacy contamination
- [ ] Community / political risk notes for jurisdiction

## 5) Commercial & offtake

- [ ] Product (concentrate, doré, cathode, etc.)
- [ ] Offtake LOIs vs binding agreements
- [ ] Pricing formulas / payability
- [ ] Logistics path to market

Debt and streaming providers care deeply about this from DFS onward.

## 6) Financial package readiness

Minimum for serious debt conversations:

- [ ] Financial model (sources & uses, monthly construction, sensitivity)
- [ ] Historical financials / audit status
- [ ] Capex/opex basis from study
- [ ] Working capital & contingency
- [ ] Existing debt / liens
- [ ] Use of proceeds by milestone

Minimum for equity teaser:

- [ ] 1–2 page teaser
- [ ] Deck
- [ ] Technical report link
- [ ] Cap table
- [ ] Ask amount + instrument (common, pref, note, royalty)

## 7) Fraud / promotion screen (junior mining specific)

- [ ] Claims match technical report (not website hype)
- [ ] No “imminent production” language without permits + funding + FS
- [ ] Stock promotion / paid IR history reviewed for public cos
- [ ] Assay labs / QA/QC disclosed
- [ ] Related-party land deals at arm’s length?

## 9) Data sources to verify claims

- SEDAR+ / EDGAR filings and technical report exhibits
- State / provincial mining claim registries
- Company-provided title opinion (counsel)
- Independent QP report — not management PowerPoint alone
- Permit registries / environmental databases where available
